起点：V2 的问题 — 模型在追涨，不是预测

核心发现：V2 模型推荐的第 1 名股票中，81% 在推荐前 20 天已经涨了 20% 以上。
模型不是在做 "妖股预判"，而是在做 "动量追涨" — 看到涨了，推荐买入，继续涨。

V2 的三个根本缺陷

❶ 标签循环

正样本定义：fwd [T+1, T+10] ≥ 30%
问题：T+1 时股票往往已经在拉板，模型学到的是 "连板中买入" 而非 "启动前埋伏"

❷ 只有动量特征

8 维 raw OHLCV 全部是价格变化率 / 成交量
天然给 已经启动的股票 最高分 — 涨得多 = 分数高

❸ 纯截面归一化

每天横向对比："今天比别人涨得多" 得高分
无法回答 "今天比自己的历史异常吗？"

V3 的设计目标

找到 启动前 的信号 — 股票还在横盘 / 缩量蓄力阶段，5-15 天后爆发

新标签定义

# V3 正样本 if max_return(T+5 → T+15) ≥ 30% and max_return(T-20 → T) < 10% → positive # 关键改动：跳过 T+1 ~ T+4 # 逼模型不看 "已经启动" 的信号 # 前 20 天必须安静 → 排除连板股

新特征体系 (20维)

动量8 dims — open_ret, close_ret, volume, turnover...
蓄力8 dims — vol_20d, vol_ratio_5d, amplitude_10d, turnover_trend, ret_skew...
背离4 dims — price_vol_div, obv_divergence, high_vol_fade, gap_ratio...

蓄力特征捕捉横盘缩量，背离特征检测价量异常

根因分析

为什么 V3 不再推荐？

跳空低开 → open_ret 大负 → close_ret 大负 → volume 异常 → 所有截面 z-score 推到负极端
截面归一化问的是 "今天比别人弱多少"，答案是非常弱 → 排名跌出 top-k

真实情况

跳空是 短期震仓 / 情绪宣泄，不是基本面的恶化
股票本身走势完好，几周后修复并继续上涨
但模型没有 "自身历史基准" 来区分异常 vs 弱势

解决方向：引入 时序归一化 (per-stock z-score) — 每只股票用自己 60 天历史做归一化。
跳空后，截面 z-score 很负，但时序 z-score 只是微微偏离 → 模型能看到 "这是异常，不是弱势"。

V4：纯 OHLCV + 时序归一化

设计思路

与其在 V3 的 20 个手写特征上叠时序归一化（可能会引入噪声），不如 回归最原始的价格/成交量数据，让 Transformer 自己从 raw data + 时序归一化中学到模式。

V3 特征 (20维)

类型内容归一化
OHLCV 动量open_ret, high_ret, low_ret, close_ret, volume, amount, turnover, mcap截面 z
蓄力 8维波动率、量比、振幅、尾盘位置、换手趋势、超额收益、偏度、量变异截面 z
背离 4维价量背离、OBV斜率、放量下跌、跳空占比截面 z

V4 特征 (16维)

类型内容归一化
Raw OHLCV (截面)8 dims — open_ret, high_ret, low_ret, close_ret, volume, amount, turnover, mcap截面 z
Per-Stock Z (时序)同上 8 维对每只股票做 60 日滚动 z-score时序 z
# 时序 z-score 计算 for each stock: rolling_mean = mean(x[-60:-1]) # 自身 60 天均值 rolling_std = std(x[-60:-1]) # 自身 60 天标准差 ts_z = (x - rolling_mean) / rolling_std

截面 z: 今天比别人强多少
时序 z: 今天比自己的历史异常多少
Concat 两者 → Transformer 自主学习权重

全流程总结

V2 — 动量追涨模型
8 维 OHLCV，纯截面 z-score，fwd [T+1,T+10] 标签
81% 首次推荐前已涨 20%+ → 本质是追涨
V3 — 启动前检测
20 维手写特征（蓄力+背离），fwd [T+5,T+15] 跳过启动期
回测 +160%，但 震仓后不再推荐
问题诊断 — 根因：截面归一化无法区分异常 vs 弱势
跳空后所有特征推到截面负极端 → 排名永久跌出 top-k
金圆股份、天通股份 等震仓后大涨 50-100% 却从未被重新买入
V4 — 时序归一化验证
Per-stock z-score 成功解决重推荐（天通 T+6 排第 3）
但 16 维纯 OHLCV 选股质量不足，val AP 0.1066 太低
V5 — 融合方案 (建议)
V3 的 20 维手写特征 + V4 的 per-stock z-score (全部 20 维) → ~40 维
兼顾 V3 选股质量 + V4 重推荐能力

V5 具体建议

特征工程

  • 保留 V3 全部 20 维手写特征
  • 对全部 20 维计算 per-stock rolling z-score (window=60)
  • Concat → ~40 维输入
  • 考虑加 per-stock z-score 的 5d/20d 多窗口

训练改进

  • 增大 dropout (CNN 0.4, Trans 0.4, Head 0.6)
  • 增大 weight decay (1e-3 → 3e-3)
  • 尝试 label smoothing 或 soft labels
  • 考虑对抗训练 (GRL) 减少截面依赖

退出策略

  • 放宽跳空止损：在 top-k 内则保留
  • 提高 model override 优先级
  • 考虑分阶段止盈而非一刀切
核心认知
时序归一化 已经证明有效 — 天通股份的案例不是偶然。问题是纯 OHLCV 太粗糙。
V5 把时序归一化应用到 V3 的手写特征上，应该能同时得到好的选股质量和重推荐能力。

另外值得思考：是不是应该取消跳空止损？ 如果模型的重推荐能力足够好，跳空就是买入机会而不是止损信号。
